About this experiment & useful references

This X assignment extends T1A05: keyboard, mouse, touch and form inputs become audio, canvas visuals, text and downloadable files. The Wave and Spectrum modes read live audio when sound is enabled. With sound off, the display is labeled as a visual preview.

No microphone, samples, libraries or internet connection are needed. Projects save in this browser when storage is available. Save project creates a portable JSON file; Load project restores it. WAV export renders the current pattern four times plus a short decay tail. Muting playback does not mute the exported file; the volume slider does affect it.

Motion follows your device by default. Choose “On for this page” to animate this artwork without changing computer settings. PULSE stops its loop when you leave this tab.

Reference: Web Audio API · OfflineAudioContext · AnalyserNode
