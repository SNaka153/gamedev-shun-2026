Fractal atlas / Shunta Nakamura
INFINITY

A universe made from one equation.

A small rule. An enormous world.

You are looking at a calculation.

zn+1 = zn² + c

Every pixel supplies a complex number c = a + bi. Start at z = 0, square it, add c, then repeat. Changing the pixel changes the entire journey.

When the size of z exceeds 2, the orbit will escape. The colour records how quickly that happens. Black means no escape was found within this drawing's iteration budget; it is a finite approximation.

Fractional escape counts blend the bands smoothly. Colour cycling changes the palette over time, while the mathematics stays the same.
