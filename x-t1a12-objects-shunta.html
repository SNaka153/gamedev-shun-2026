BEHIND THE MISSION
A rover is an object.
One shared rover object keeps the explorer's properties together. The controls change those properties, and the map reads the new values.
Named properties
rover.name = "Scout" changes a string. Health and level hold numbers.
A nested object
rover.position.x += 1 changes a value inside the position object.
An array property
rover.inventory.push(sample) adds a collected sample. Each sample is also an object.
Reading the result
The live object panel shows the current properties. Copy JSON uses JSON.stringify(rover, null, 2) to turn the object into text.
