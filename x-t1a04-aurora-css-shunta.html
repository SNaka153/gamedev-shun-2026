What makes this an X assignment?

This extends T1A04 CSS with a live design tool: gradients, layered shadows, frosted glass, 3D transforms, animation, responsive layouts and reusable exports.

JavaScript connects controls and saves settings; CSS draws and animates the artwork. The main assignment stays on its own page.
