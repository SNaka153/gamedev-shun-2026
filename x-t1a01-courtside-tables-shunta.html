A table that runs a tournament.

COURTSIDE is Shunta's X assignment for T1A01 Tables. It turns HTML tables into a working volleyball tournament desk.

One result. Four views.

Scores live in one match list. Every edit rebuilds the standings, fixtures, comparison and head-to-head matrix from that list. Correcting a match replaces its result; it never adds the same result twice.

How ranking works in this demo

Rank by table points, then wins, then set difference. Teams still equal share a rank and are displayed alphabetically. A leading team is provisional until all matches are played. An unbeaten team must have played at least once.

Tables beyond the basics

  • caption, thead, tbody and tfoot give tables structure.
  • scope identifies row and column headers.
  • colspan creates round headings across the fixtures table.
  • Sortable columns, a sticky team column on small screens and a symmetric match matrix make the data useful.

Keep your tournament

Edits are saved in this browser when storage is available. JSON export is a portable backup. CSV exports all six teams in ranking order, regardless of search or column sorting. No information is sent to a server.
