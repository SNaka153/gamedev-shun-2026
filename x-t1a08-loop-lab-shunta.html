What makes this a Loops assignment? + shortcuts
01 · A loop makes a pattern
for (let myStep = 0;
     myStep < mySteps;
     myStep++) {
  myPattern.push(
    (myStep * myNotes) % mySteps
      < myNotes
  );
}
This distributes exactly myNotes hits around mySteps positions. Shift rotates that result; painting edits its true/false entries.
02 · A loop inside a loop
The outer loop advances the tick. The inner loop visits every track. The score preview, generated JS, and WAV renderer all use the same decisions.
Another pair of nested loops draws each track's geometry and its threads. One small rule builds hundreds of lines.
The alignment cycle uses the least common multiple of the four lengths. It is where all positions return to zero; a rhythm can repeat sooner.
