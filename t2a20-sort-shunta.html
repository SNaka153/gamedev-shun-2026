Sorting Arrays

This page demonstrates how computers sort numbers using arrays, loops, comparisons, and temporary variables.

How swapping works

Example: [3, 7, 0, 4, 2]

Compare 7 and 0. Since 7 is greater than 0, they must switch places. 

myTemp = 7
Move 0 into the second position
Move myTemp (7) into the third position

Result: [3, 0, 7, 4, 2]

After sorting: [0, 2, 3, 4, 7]

Sorting Methods

Bubble Sort: Compares neighboring numbers and swaps them when they are in the wrong order.

Selection Sort: Finds the smallest remaining number and moves it into the correct position.

Reverse Sort: Uses Bubble Sort but arranges numbers from largest to smallest.

Animated Sort: Shows the comparisons and swaps step by step.
