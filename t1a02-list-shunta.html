Five Types of Whales

  1. Humpback whale
    • It has very long flippers.
    • Learn about humpback whales
  2. Killer whale
    • Also called an orca, it belongs to the dolphin family.
    • Learn about killer whales
  3. Blue whale
    • It is the largest animal on Earth.
    • Learn about blue whales
  4. Gray whale
    • It makes long migrations in the North Pacific.
    • Learn about gray whales
  5. Sperm whale
    • It dives deep to find food such as squid.
    • Learn about sperm whales
