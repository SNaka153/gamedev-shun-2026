Create a complete, single-file HTML and vanilla JavaScript web application titled "Offline Vision Quest". The application must be self-contained within one file with minimal inline CSS styling (no external CSS files, frameworks, or CDNs). 

### Coding & Naming Conventions:
- All custom JavaScript variables and functions must use camelCase and be prefixed strictly with "my" (e.g., myGameRunning, myStartGame, myActivateCamera).
- Keep code clean, readable, and well-structured, suitable for teaching high school technology students.

### Functional Requirements:

1. Layout & UI:
- A clean layout containing two main sections: a Camera/Training panel and a Live Prediction/Game panel.
- Simple, readable inline CSS styling without heavy gradients, custom web fonts, or complex shadow styling.

2. Camera Lab & Feature Extraction:
- Controls to select camera facing mode (front/user or rear/environment) and buttons to "Activate WebCam" and "Stop".
- A live video preview element (`<video>`).
- A processing canvas sized 16x16 pixels (`image-rendering: pixelated`) that mirrors the video horizontally using context transformation (scale(-1, 1)) so that left/right movements align intuitively with the user.
- Extracts an 16x16 grayscale feature vector (256 normalized values between 0 and 1) from each frame for the local machine learning classifier.

3. ML Training Engine:
- Five distinct training classes: UP, DOWN, LEFT, RIGHT, and NEUTRAL.
- Training buttons utilizing pointer events (`onpointerdown`, `onpointerup`, `onpointerleave`) that support continuous sample collection when held down.
- Counters tracking the number of samples collected per class and the total sample count.
- Buttons to clear training data, **Save Model** (exports a JSON file containing the training sample arrays), and **Load Model** (imports a JSON file to restore training samples). No image saving should be included.

4. Live Prediction Engine:
- A real-time k-NN (k-Nearest Neighbors) distance classifier that compares current 16x16 frame features against stored training samples.
- Displays the current predicted label and confidence percentage on screen.

5. Treasure Game Canvas:
- An HTML5 canvas game (400x300 pixels) where an explorer player must collect 3 randomly placed treasures.
- Player movement is driven by the real-time classifier confidence vector or via keyboard arrow keys / WASD fallback.
- An adjustable number input box allowing the user to change the character's base movement speed dynamically during gameplay.
- Game controls for Start / Resume, Pause, and Reset Game, along with a counter for collected treasures and current movement speed.
