    BEHIND THE CLASS
    One class. Many heroes.
    A class describes how to create an object and what it can do. Each hero is a separate instance of myGamePlayer.
    constructor
    Runs when you use new. It sets the new hero's name, health, equipment, and other starting values.
    this
    Refers to the instance calling the method. party[0].myHeal(25) heals the first hero.
    Methods
    myTakeDamage(), myHeal(), myLevelUp(), and myAddItem() work on that hero's properties.
    Independent instances
    Training Aster changes Aster's health and experience. Lyra and Finn keep their own values and inventories.
